SpeedArti Couvreur V0.5.1

Connecteur préparé

Le dépôt source GSTAI-Sp/speedarti-v2 a été analysé uniquement en lecture. Aucun fichier de production n'a été modifié.

Contrat cible

Wizard → Couvreur → moteur métier → paramètres techniques du modèle exact → catalogue prix → stock → résultat → sauvegarde. La transformation en devis reste une action volontaire de l'artisan.

Correction principale

La quantité de tuiles n'est plus basée sur une famille générique. La démo utilise la consommation du modèle fabricant. Quand la fiche donne une plage, la moyenne fabricant est utilisée par défaut et l'artisan peut retenir une autre valeur dans la plage.

Bibliothèque VELUX

Choix modèle/gamme/dimension, raccord d’étanchéité et accessoires BDX/BFX/BBX avec prix sourcés. Le -15 % est une estimation artisan de démonstration et non un tarif professionnel VELUX contractuel.

Sécurité

Options et dimensions de sécurité sont regroupées sur une seule page.

Ángel

angel-knowledge-base.json est le payload Couvreur destiné à enrichir la base Ángel existante. Il ne constitue pas une nouvelle base runtime indépendante.
